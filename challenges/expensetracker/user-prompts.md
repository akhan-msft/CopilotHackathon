# User Prompts — Expense Tracker Challenge

Chronological list of prompts used to go from requirements to a fully working implementation.

---

1. **Virtual environments & startup script**
   > "Set up Python virtual environments for dependency isolation and create a single startup script (`start.ps1`) to launch both the backend and frontend servers."

2. **UI redesign with tabs & Material Design**
   > "Split the graphs into a separate tab, keep the main page for adding expenses and viewing the table, use Material Design styling, and I'm open to a different frontend framework."

3. **Fix form field label contrast**
   > "The field labels aren't showing — poor contrast against the dark background."

4. **Fix selectbox dark background**
   > "The Category selectbox still has a dark background making text invisible."

5. **Consider Bootstrap / alternative to Streamlit**
   > "Could you maybe use Bootstrap to help with the look and feel of a modern web app?"

6. **Confirm replacing Streamlit**
   > "Do you think another UI implementation would be better than Streamlit?"

7. **Approval of Bootstrap migration**
   > *(Agreed to replace Streamlit entirely with an HTML + Bootstrap 5 + Chart.js single-page app served by a lightweight Python static server.)*

8. **Positive feedback**
   > "That is much much better, thank you."

9. **This file**
