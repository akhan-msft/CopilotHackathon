# User Prompts — WebSocket Chat Challenge

Chronological list of prompts used to go from requirements to a fully tested implementation.

---

1. **Implementation plan**
   > "Use this requirements file to create an implementation plan for me in python, there is an index.html that you can use, let me and use the references included in the document as specified. Keep the impl simple and not over engineer"

2. **Start implementation**
   > "Start implementation"

3. **Keep files self-contained**
   > "pls ensure everything remains within the chatwebsockets root folder"

4. **BDD test plan**
   > "ok can you create a BDD plan to test this implementation using playwright MCP server?"

5. **Implement the tests**
   > "use the implementation you feel would be best and implement accordingly"

6. **Run tests live + create README**
   > "can you use the playwright mcp server to test on a localhost url and run these tests so i can see the tests in action? also, create a test.readme.doc to outline how to run the tests"

7. **Local test steps**
   > "so what are the steps for me to test locally?"

8. **Manual app launch**
   > "how can i launch the app to test myself and not via chromium or playwright?"

9. **This file**
   > "can you please summarize all the prompts i specified to get to the end solution in chronological order in a user-prompts.md file?"
